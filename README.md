# Sales Data Cleaning & Analysis Using SQL

This project focuses on cleaning and analyzing a sales dataset using SQL.

### What I worked on

* Cleaned missing and invalid data
* Replaced `#N/A` values with `NULL`
* Explored sales performance
* Analyzed transactions and employees
* Examined the effect of promotions on sales
* Used SQL queries to answer business questions

### Tools Used

* SQL
* SQLite / DB Browser for SQLite

### Key SQL Skills

* `SELECT`
* `WHERE`
* `GROUP BY`
* `HAVING`
* `ORDER BY`
* Aggregate functions such as `SUM()` and `COUNT()`
* Data cleaning
